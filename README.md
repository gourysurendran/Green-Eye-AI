## Project Overview
Green Eye is an AI-powered farmer guidance system designed to assist farmers in making better agricultural decisions. The platform integrates artificial intelligence, agricultural knowledge, and real-time data to provide intelligent recommendations for crop management.

---

## Key Features
- 🌿 Plant Disease Detection using CNN
- 🌱 Crop Recommendation System
- 💧 Smart Irrigation Guidance
- 🧪 Fertilizer Recommendation
- 📊 Market Price Insights
- 💰 Government Scheme Guidance
- 🤖 AI Chatbot for farmer queries
- 📅 Crop Calendar and alerts

---

## Technologies Used
- Python

- HTML

---

## How It Works
1. The user uploads a plant leaf image.
2. The CNN model analyzes the image.
3. The system predicts the disease.
4. Farmers receive guidance and treatment suggestions.
